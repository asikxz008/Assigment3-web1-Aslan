# Discover Kazakhstan

A responsive five-page guide to Almaty, Astana, and Turkistan for WEB Technologies 1 Assignment 3. Created by Sabyr Aslan (SE-2528).

## Pages

- Home: introduction and navigation
- Destinations: three city guides
- Routes: sample three-day routes in a table
- Gallery: six original SVG illustrations
- Plan a trip: a city selection form with CSS-only results

Built with semantic HTML, custom CSS, Flexbox, Grid, media queries, and locally stored Bootstrap 5.3.8 CSS. Open `index.html` to view it locally.

Live site: https://asikxz008.github.io/Assigment3-web1-Aslan/

Travel references: [Kazakhstan Travel](https://kazakhstan.travel/en), [UNESCO](https://whc.unesco.org/en/list/1103/). Bootstrap license: [vendor/BOOTSTRAP-LICENSE.txt](vendor/BOOTSTRAP-LICENSE.txt).
